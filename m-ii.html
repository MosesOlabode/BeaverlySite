Separation of responsibilities

Not a language model with broker access.

Conversation and financial execution are separate responsibilities. Chilla handles the relationship with you. M-II handles authorized live work through an engineered execution path.

Chilla

Understands what you’re working towards, talks with you, explains, checks in, and reports back.

M-II

Receives authorized work, keeps it scoped, checks it, executes it through the right provider lane, and maintains the trace.

Integrity before activity

Built to refuse work.

A serious execution system needs a reliable way to say no. M-II can defer or block an action when required execution conditions are not intact.

01Stale

The event is no longer fresh enough for the intended action.

02Duplicate

The system detects a repeat path that should not execute again.

03Wrong lane

Account, symbol, scope, or workload compatibility does not match.

04Outside bounds

Capacity, account constraints, or user-defined financial boundaries would be exceeded.

Isolation

Each workload stays in its lane.

M-II supports multiple active workloads without letting one overwrite another. Routing preserves the user, account, market, and authorized work context all the way to execution.
